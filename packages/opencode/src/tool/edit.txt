Performs exact string replacements in files. 

Usage:
- You MUST view the target file first (e.g. `sed -n '1,200p' path` or `cat path`) before editing. Editing a file you have not viewed will fail or damage it.
- Match the exact file bytes, preserving tabs and spaces precisely. Do not invent or approximate content you have not seen.
- ALWAYS prefer editing existing files in the codebase. NEVER write new files unless explicitly required.
- Fails if `oldString` is absent or matches multiple places. For multiple matches, add surrounding context to make it unique, or set `replaceAll` to replace every occurrence (useful for renames).
