Launch a new agent to handle complex, multistep tasks autonomously.

Specify `subagent_type` to choose the agent.

When NOT to use the Task tool:
- To read a known file path, use `cat` / `sed -n` directly
- To search for a token like "class Foo", use `grep -rn` directly
- If the work fits in one or two shell commands, do it yourself
- If no available agent fits the task, handle it directly with `bash`

Usage notes:
1. Launch multiple agents concurrently when independent (multiple tool uses in one message).
2. Once delegated, do not duplicate the work yourself; continue non-overlapping tasks or wait for the result. Background tasks notify you when ready.
3. The agent returns a single message that is NOT visible to the user — summarize it for the user. The output includes a `task_id` you can reuse to resume the same subagent session.
4. Each invocation starts with fresh context unless you pass `task_id` to resume. When starting fresh, write a highly detailed prompt stating exactly what the agent should do and what it should return in its final message.
5. Tell the agent whether you expect code changes or just research (search, reads, fetches), and how to verify its work (e.g. test commands).
