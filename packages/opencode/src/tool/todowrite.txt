Create and manage a structured task list for tracking progress on complex tasks. Helps the user see your progress.

## When to Use
- Complex multistep tasks (3+ distinct steps)
- User provides multiple tasks (numbered or comma-separated)
- User explicitly requests a todo list
- After receiving new instructions, capture requirements as todos
- Mark todos in_progress when starting, completed immediately when done. Only ONE in_progress at a time.

## When NOT to Use
- Single straightforward task or trivial task (<3 steps)
- Purely conversational or informational requests

<example>
User: Add dark mode toggle. Run tests and build when done!
Assistant: *Creates todos:* 1) Dark mode toggle component 2) State management 3) Theme styles 4) Update components 5) Run tests and build
*Begins first task*
</example>

<example>
User: How do I print 'Hello World' in Python?
Assistant: [Answers directly without creating todos - single trivial task]
</example>

## Task States
- pending / in_progress (limit ONE) / completed / cancelled
- Mark complete IMMEDIATELY after finishing, don't batch
- Create specific, actionable items with clear names
